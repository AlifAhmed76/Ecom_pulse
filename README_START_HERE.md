# Last Year Project - Developer Handoff Package (এখান থেকে শুরু করুন)

এই প্যাকেজে **কোড নেই**। আছে: পূর্ণ নকশা, নিয়ম, ১৮টা ছোট কাজ (T00-T17) আর Gemini-কে দেওয়ার প্রম্পট।
আপনি = Product Owner, Gemini + Antigravity = Developer, Claude (আমি) = Instructor/Reviewer।

## ধাপ ১: নিজের পিসি যাচাই করুন (এটা আপনাকেই করতে হবে)
Command Prompt-এ চালান এবং ফল লিখে রাখুন:
```
php -v                 (লাগবে 8.2 বা তার বেশি)
composer -V            (থাকতে হবে)
git --version          (থাকতে হবে)
php -m                 (এই তালিকায় থাকতে হবে: mbstring, pdo_mysql, pdo_sqlite, zip, xmlreader, dom, fileinfo, openssl, curl)
```
XAMPP Control Panel থেকে **MySQL** চালু করুন। `php` কমান্ড না পেলে XAMPP-এর `C:\xampp\php` ফোল্ডার PATH-এ যোগ করুন।
কিছু না থাকলে T00 কাজটাই আপনাকে ধাপে ধাপে ইনস্টল করাবে। না জানলে ফলটা আমাকে পাঠান।

## ধাপ ২: ফোল্ডার সাজান
1. একটা খালি ফোল্ডার বানান, যেমন `C:\projects\lastyear-workspace`।
2. এই zip-এর সব কিছু সেখানে খুলুন (docs, tasks, prompts, reference, GEMINI.md, AGENT_RULES.md)।
3. সেই ফোল্ডারে `git init` চালান।
4. `reference/` ফোল্ডার **শুধু পড়ার জন্য**। ওটা আমার আগের কোড, যা কখনো চালানো হয়নি। Gemini ওখান থেকে ধারণা নিতে পারবে, অন্ধভাবে কপি করবে না।

## ধাপ ৩: Gemini / Antigravity-কে শুরু করান
- Antigravity-তে এই ফোল্ডারটা workspace হিসেবে খুলুন।
- `AGENT_RULES.md`-এর লেখা ওর rules/instructions সেটিংয়ে রাখুন (সেটিংয়ের নাম ও জায়গা সংস্করণ অনুযায়ী আলাদা, আমি যাচাই করিনি)। Gemini CLI হলে `GEMINI.md` ফাইলটি এই ফোল্ডারে আছে।
- `prompts/FIRST_MESSAGE.md`-এর লেখা Gemini-কে প্রথম বার্তা হিসেবে দিন। সে কোড লিখবে না, শুধু বুঝেছে কিনা জানাবে।
- তার উত্তর আমার কাছে আনুন। আমি দেখব সে ঠিক বুঝেছে কিনা।

## ধাপ ৪: প্রতিটা কাজের চক্র (বারবার)
1. `tasks/T00_...md` থেকে শুরু করে **একটা** কাজ খুলুন। `prompts/TASK_PROMPT_TEMPLATE.md`-এর ছাঁচে Gemini-কে দিন।
2. Gemini কাজ করে রিপোর্ট দেবে।
3. **আপনি নিজে** `php artisan test` চালান। Gemini-র "পাস" লেখা বিশ্বাস করবেন না।
4. `prompts/REVIEW_REQUEST_TEMPLATE.md` অনুযায়ী রিপোর্ট, `git diff --stat` আর টেস্টের শেষ অংশ আমাকে পাঠান।
5. আমি "পাস, পরের কাজ" বা "এই জায়গা ঠিক করো" লিখে দেব। সেটা Gemini-কে দিন।
6. পাস হলে `git commit`। ভুল হলে `git revert` বা আগের কমিটে ফিরুন।
