# DEMO PLAN (teacher / investor / client) - must work OFFLINE
Demo mode (T16): one button seeds deterministic fake data for the current tenant (marked source=demo, removable with one click): 1 website, ~40 products with costs, ~2,500 orders over 120 days with realistic status mix, 3 couriers (one deliberately worse), 4 employees (one deliberately higher cancel rate), courier shipments, ad rows, history rows. Findings appear after "Run scan".
Script (10 minutes):
1 Two companies log in; show neither can see the other's data. 2 Plain dashboard opens instantly (explain cache + scheduler). 3 Upload a CLIENT'S OWN CSV/XLSX/XML live -> mapping screen -> results in under a minute. 4 Analytics page: definitions, freshness, data-quality score. 5 "Money lost" report + courier scorecard (the investor headline). 6 R&D Action Center: open a finding, point out evidence, confidence, hypotheses, missing data. 7 Create an experiment, approve it (role check), close it with a result. 8 Audit log: tamper with a row in the DB, click Verify -> failure detected. 9 (If LLM on) "AI explanation" button, labelled as hypothesis; if off, say it is optional. 10 Weekly summary in Bangla, print preview.
Fallbacks: LLM off -> skip step 9. No worker -> imports run synchronously. No internet -> nothing in the demo needs it.
Pre-demo checklist: MySQL running, run.bat started 4 windows, System page shows scheduler/worker running, demo data seeded, sample files on the desktop, test run green.
