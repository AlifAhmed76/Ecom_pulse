# DECISIONS LOG

Conflicts and design choices resolved during autonomous build (Authority order: `docs/original_brief.pdf` -> `docs/DECISIONS.md` -> `AGENT_RULES.md` -> other specs).

1. **Stack & Runtime (`original_brief.pdf` Sec 4/11 vs `DECISIONS.md`)**: `original_brief.pdf` listed Livewire, Python FastAPI, PostgreSQL, Redis, Docker as proposed architecture and left final platform decisions open in Section 11. `DECISIONS.md` locks PHP 8.2+, Laravel latest stable, MySQL (XAMPP), Blade + vanilla JS + local Chart.js, OpenSpout ^4, file cache/session, database queue for offline Windows demo portability, while keeping SQL portable to PostgreSQL. Followed `DECISIONS.md`.
2. **Primary Keys (`original_brief.pdf` Sec 6 vs `DECISIONS.md`)**: `original_brief.pdf` allowed UUIDs "if chosen"; `DECISIONS.md` locked auto-increment bigints. Followed `DECISIONS.md`.
3. **Deferred Features (`original_brief.pdf` Sec 3 vs `DECISIONS.md`)**: Chatbot order creation, website ownership live verification, live courier APIs, live ad-platform APIs, and live Cloudflare API calls are deferred in `DECISIONS.md` (replaced by grounded Q&A + order lookup, stored `verification_token` shown as "not verified", CSV importers, and app-level `security_events` + WAF docs). Followed `DECISIONS.md`.
4. **Laravel Project Location (`T00_environment.md` vs `MASTER_PROMPT.md`)**: `T00` references `composer create-project laravel/laravel lastyear`, while `MASTER_PROMPT.md` expects `artisan`, `docs/`, `AGENT_RULES.md`, `REVIEW_BUNDLE/`, and `git archive` at one repository root (`c:\Users\USER\Desktop\EcomPulse`). Created the Laravel project cleanly in a temp staging folder and merged it into the repository root so `artisan`, `app/`, `docs/`, `tasks/`, and `AGENT_RULES.md` share a single clean Git repo root (`reference/` excluded).
5. **PHP `zip` Extension (`T00`)**: `php_zip.dll` is present in `C:\php-8.2.10\ext` and `C:\xampp\php\ext` while `;extension=zip` is commented in `php.ini`. Commands and `.bat` wrappers pass `-d extension=zip` when needed and `setup.bat` + `FINAL_REPORT.md` highlight enabling `extension=zip` in `php.ini`.
6. **UI/UX Design System (`UI_GUIDE.md` + Owner UI direction)**: To avoid generic AI cliché styling while keeping strict compliance with `UI_GUIDE.md` (single local CSS file, local Chart.js, no CDN, no external fonts, EN/বাংলা support, plain <=6-counter dashboard, print stylesheet, accessible contrast), adopted a restrained light-mode SaaS design system: `#F8FAFC` slate canvas, `#FFFFFF` cards with `#E2E8F0` 1px hairline borders, `#0F172A` primary ink, `#1E40AF` / `#2563EB` restrained cobalt accent, semantic status badges, `tabular-nums` on all financial/metric figures, and structured sidebar + sticky header navigation.
